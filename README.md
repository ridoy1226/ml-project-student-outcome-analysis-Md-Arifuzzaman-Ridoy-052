## Problem Idea

This project explores a small student dataset to understand the relationship between academic-related factors and student outcomes. The notebook uses study hours, sleep hours, attendance, and snacks as features, with `passed` as the target label.

## Current Dataset Status

The current dataset is a small manually created dataset containing **6 student records**. It includes the following features:

* `study_hours`
* `sleep_hours`
* `attendance`
* `snacks`

The target label is:

* `passed`

The notebook also demonstrates basic NumPy and Pandas operations, including data inspection, descriptive statistics, filtering, sorting, and basic analysis.

## How to Run the Notebook

1. Clone or download this repository.
2. Install the required Python packages:

```bash
pip install -r requirements.txt
```

3. Open Jupyter Notebook or Google Colab.
4. Open the notebook:

```text
notebooks/ML_Lab01_20245103052_Md_Arifuzzaman_Ridoy.ipynb
```

5. Run the notebook cells sequentially from top to bottom.
